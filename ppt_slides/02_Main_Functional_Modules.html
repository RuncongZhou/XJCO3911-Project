Main Functional Modules
1
Model & Layer Management
Load DNN models (AlexNet, Vgg19, YOLONet), display layer hierarchy and attributes (FLOPs, data size, type).
2
Device & Topology Config
Set device count, bandwidth and performance range, generate device topology and order.
3
Partition & Simulation
Algorithm partition (HiveMind / EdgePipe) or user-defined ranges; pipeline simulation and throughput / latency.
4
Visualization & Comparison
Model structure, topology, partition scheme, metrics; side-by-side algorithm comparison.
