System Architecture
1
User / Presentation Layer (Browser)
Configuration panel (model, device count, algorithm, bandwidth, partition design). Visualization tabs: model structure, device topology, partition scheme, performance metrics, algorithm comparison.
HTTP (JSON)
2
Service Layer (Flask Backend)
REST API: /api/model/<name>/layers, /api/simulate, /api/device-topology, /api/compare. Runs partitioning algorithms (HiveMind, EdgePipe) or evaluates custom partition; returns throughput and inference time.
3
Data & Algorithm Layer
Layer metadata (CSV: Flops, DataSize, type, height). Partitioning and pipeline simulation logic (HiveMind, EdgePipe).
Flow: User operation → Frontend request → Backend API → Algorithm / Data → Response (partition, metrics) → Frontend display.
